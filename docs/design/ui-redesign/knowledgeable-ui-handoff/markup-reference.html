Prime numbers

Solid, 98%

Building blocks that can't be broken into smaller whole-number factors.

Think back to divisibility: a number divides another if it splits evenly with nothing left over. A prime is the opposite, a stubborn number that refuses to split.

Picture seven tiles. You can't arrange them into a rectangle more than one row high, so 7 is prime.
